# Security Policy

## Supported versions

Security fixes target the latest published release in the current minor release line (0.1.x). Upgrade to the latest patch before reporting a suspected issue. Older release lines are unsupported.

## Private vulnerability reports

Use [GitHub private vulnerability reporting](https://github.com/lafittemehdy/veil/security/advisories/new), or email lafittemehdy@gmail.com if that channel is unavailable. Do not include exploits, credentials, personal data, or undisclosed vulnerability details in public issues.

Include affected versions, impact, prerequisites, a minimal safe reproduction, and any known workaround. Maintainers will coordinate investigation and disclosure; no fixed response time or security guarantee is promised.

## Deployment boundaries

Consumers remain responsible for sanitizing untrusted content and media URLs. Keep React and application dependencies supported. Review keyboard access, reduced motion, and visible controls when integrating these visual components.
